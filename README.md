# MeharajCAD

MeharajCAD is a planned Windows desktop application for professional jewellery design and manufacturing. The proposed foundation combines Rust application services, C++ CAD geometry, Open CASCADE Technology (OCCT), and Qt 6.

## Status

**Architecture planning.** This repository does not yet contain a working CAD application. The first milestone is architecture review and a reproducible Windows toolchain spike.

## Direction

The long-term goal includes parametric jewellery workflows, gemstones and settings, manufacturing calculations, file exchange, project libraries, and optional AI assistance. These are planned capabilities, not implemented features.
